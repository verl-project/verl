PPO Trainer
===========

Last updated: 11/10/2026.

``verl.trainer.main_ppo`` runs the V1 trainer. Set
``trainer.v1.trainer_mode`` to ``sync``, ``colocate_async``, or ``separate_async``.
See :doc:`../advance/v1_async_trainer` and :doc:`../api/trainer`.

The V0 trainer has been removed from mainline. The async recipes in
`verl-recipe <https://github.com/verl-project/verl-recipe>`_ use verl v0.9.1.
